# 行为准则

[English](../../CODE_OF_CONDUCT.md) | 简体中文 · [文档目录](README.md)

欢迎不同背景和经验的贡献者。保持尊重、耐心和具体，针对观点与代码提出意见，提供必要上下文，尊重不同沟通方式。欢迎用任何语言提问。

不接受骚扰、歧视、威胁、性相关不当行为、人身攻击或公开他人隐私。本准则适用于项目 issue、PR、审阅及其他项目空间。

维护者可编辑或移除有害内容、警告参与者、限制参与，或封禁重复/严重违规者。处理应考虑影响和具体情境，维护者同样遵守准则。

公开行为问题可通过 GitHub 的 **Report content** 功能举报，或通过[仓库所有者主页](https://github.com/philpm)提供的联系方式联系。敏感细节仅通过私密渠道分享，维护者仅向处理所需人员披露。申诉可通过同一渠道补充上下文。

软件漏洞请遵循[安全说明](SECURITY.md)。
