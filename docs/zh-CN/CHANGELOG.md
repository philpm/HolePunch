# 更新记录

[English](../../CHANGELOG.md) | 简体中文 · [文档目录](README.md)

## 0.4.0-dev.1 — 首个公开预发布版本

- 为 Linux x64/ARM64、macOS x64/ARM64 和 Windows x64 提供服务端/CLI 可移植归档及 SHA256 校验和。
- 在各目标平台验证归档中的安装器、二进制版本、登录、重启、凭据保留和退出。
- 构建元数据记录产品与共享核心的源码提交。
- 此开发预发布不含已签名桌面安装包和公开容器镜像。

- 原生进程监督器支持 Windows 控制台中断退出。

### CI 与依赖维护

- 修复 Windows CRLF 文件的翻译源版本检查。
- 将 TLS/QUIC 依赖更新至已修复漏洞的 Rustls 0.23.46、Quinn-proto 0.11.18、Rustls-webpki 0.103.16 和 Webpki-roots 1.0.10。
- 更新加密和 TOML 依赖，保持旧密码哈希、令牌编码及 rathole 配置兼容。
- 更新桌面工具和 GitHub Actions，合并兼容依赖 PR、避免重复 CI，并保留已验证的 Rust 基线。
- 共享依赖审计支持下游仓库及明确指定的锁文件。

### 双语文档

- 围绕特性、完整快速开始、配置和贡献资源重写两个项目首页。
- 增加简体中文首页，以及配套用户、开发和社区指南，检查对应英文源版本。
- 原生归档包含翻译文档和项目图标。

### 开源维护

- 两个产品与包元数据统一 Apache-2.0。
- 补充贡献、支持、行为准则、国际化和维护指南。
- 整合产品文档，将内部验收日记移出公开历史。
- CI 检查仓库规范和文档链接，保留中英文国际化验证。

### 首次使用

- 登录页和控制台顶部均可见语言切换。
- 两个版本共享认证后的四步管理员设置，持久保存完成状态、原子配置更新并可更换密码。
- 原生安装或 Compose 就绪后显示访问 URL 和初始凭据，保存受保护摘要，并支持 `--hide-secrets`。
- 区分设备接入码与管理员 API 令牌，说明公网 DNS/防火墙和已有网站共存要求。

### 部署工具

- 加入支持源码/归档/发布版本的交互原生安装器，含私密配置、校验和、端口冲突检查与共享进程监督器。
- 支持 Linux systemd、Shell/PowerShell 入口、跨平台 Python sidecar 构建及 Linux ARM64 发布配置。
- 明确原生、克隆构建运行与 Linux Docker Compose 三条路径。
- 修复发布版 Compose 的初始管理员凭据，两种 Compose 支持一致的自定义端口。
- 增加部署回归和真实原生生命周期冒烟，容器镜像仍待发布。

### Self-hosted 特性

- 从当时的私有 Cloud 仓库分离共享核心、Self-hosted 与共享 CLI，桌面仍可选。
- 增加管理员密码会话、一次性 CLI 接入、自定义/随机域名及可选隧道限速，不做累计流量统计。
- 增加 schema 4 不限速策略、版本绑定数据目录、服务端网关和恢复测试。
- 控制台改为侧栏页面，支持移动导航与草稿保护。
- 扩大补丁版 rathole UDP 接收缓冲，不改变线协议。
- 整合现行文档、隔离兼容资源，将历史草稿和审计快照移出工作区。
- 建立英文原文文档/注释/CLI/API 诊断规范，以及中英文 Web/桌面共享翻译、持久语言选择和词条验证。
- 这是开发版本，不是公开稳定版。

## 0.2.0-rc.2 — 本机网站

- 增加持久化本机网站管理、回环 HTTP 代理和自动 TLS 授权。
- 网站、隧道、控制台共享域名/端口冲突检查，网站不受设备撤销或入口重启影响。
- 增加 schema 2 迁移、备份恢复、浏览器管理和真实 HTTPS 共存测试。
- 增加原生、Docker 和 PHP 应用共存指南。

## 0.2.0-rc.1 — 社区候选版

- 临时控制平面中断自动恢复，90 秒授权租约过期暂停，成功同步后恢复；明确撤销停止进程并移除缓存服务凭据。
- 客户端日志上限约 4 MiB，增加应用内诊断与本地解绑。
- 增加 schema 检查、期望状态/审计原子事务、WAL 在线备份、带旧数据保留的锁定恢复，以及单实例目录锁。
- 分离存活和入口就绪、增加诊断/近期操作 API、支持 SIGTERM 关闭和 Docker 日志上限。
- 增加可移植归档、校验和、候选 CI 产物、OCI 导出、systemd 单元和固定镜像部署模板。
- 此版本是候选，不代表已签名或公开发布二进制，仍需发布验收。

## 0.1.0 — 初始 MVP

Axum 控制平面、SQLite 配置、TCP/UDP/Web 隧道、Caddy On-Demand TLS、rathole Noise 传输、Tauri 桌面与 CLI，以及初始集成测试。
