# 语言与国际化

[English](../I18N.md) | 简体中文 · [文档目录](README.md)

文档原文、代码注释、标识符、CLI 帮助、API 诊断和示例以英文为准。维护中的 Web 控制台、兼容控制台及可选桌面 GUI 支持**英文（`en`）**和**简体中文（`zh-CN`）**。新安装始终默认英文，不跟随系统或浏览器语言。

登录页、控制台和设置向导顶部都有语言选择器，登录前也可使用。选择按浏览器/webview 保存在 `holepunch.locale`，不支持或无法读取的设置回退英文。切换保留路由和表单值，桌面同时更新托盘菜单。不翻译账户、命令、API 字段、域名、用户资源名或原始日志。

## 来源与打包

| 路径 | 用途 |
|---|---|
| `web/locales/en.json` | 英文规范消息，键与英文原文相同 |
| `web/locales/zh-CN.json` | 同键的简体中文翻译 |
| `web/i18n.js` | 共享运行时、安全插值、偏好保存与静态 HTML 翻译 |
| `web/locales/catalogs.js` | 提交的离线生成包，Rust 构建无需额外工具 |
| `scripts/sync-i18n.py` | 检查键、占位符、模板结构及生成包 |
| `tests/i18n.test.cjs` | 回退、持久化、插值和数据保护回归 |

服务端将 `/i18n.js`、`/locales/catalogs.js` 与控制台一起嵌入。桌面 `build.rs` 复制到 UI 目录，生成副本不纳入 Git；托盘直接读取源目录。不使用 CDN 或翻译 API，只有 UI 测试需要 Node。

## 新增或修改消息

1. 在 `en.json` 中以清晰英文同时作为键和值。
2. 在每个其他语言目录添加相同键及翻译。
3. 动态 UI 文本使用 `HPI18n.t`（应用中别名 `tr`），标签模板使用编号占位符，允许调整语序。
4. 静态 HTML 保持英文。运行时在应用渲染前捕获目录支持的文本、标题、占位符和无障碍标签，不会随后任意翻译用户内容。
5. 重新生成词条包，在两种语言下检查空状态、加载、错误和打开的对话框。

```js
const {t: tr} = HPI18n;
button.textContent = tr('Save changes');
// Catalog key: "Request failed ({0})"
const message = tr`Request failed (${response.status})`;
```

翻译可调整 `{0}`、`{1}` 等顺序，但必须保留各占位符出现次数。插值只执行一次，用户值中的花括号保持字面量。新增消息使用完整句子，避免拼接语法碎片。

部分表格模板包含静态 HTML。词条是可信、经审阅的源码，不是用户输入；需保留标记和属性结构，并保留资源数据的 `esc`/`escape` 调用。新增纯文本优先使用 `textContent`，不要将已渲染的完整用户字符串送去翻译。

API 诊断保持英文，不构成稳定错误代码约定。界面翻译已知消息，未知框架/系统诊断回退英文，原始细节和 rathole 日志保留用于支持与检索。

日期和时间使用所选语言环境；带宽显示按语言格式化，数字表单值和传输字段保持语言无关。

```sh
python3 scripts/sync-i18n.py
python3 scripts/sync-i18n.py --check
node --test tests/i18n.test.cjs
cargo build --workspace --locked
```

CI 检查词条一致性与生成结果。英文文档具有规范效力，译文回链原文并记录内容版本。

## 新增语言

复制英文 JSON 为 BCP 47 语言文件并翻译所有值，在每个 HTML 选择器添加该语言本地名称，扩展桌面 `set_locale` 以读取同一词条目录。重新生成后检查持久化、插值、布局、键盘访问和桌面打包。需要从右向左排版的语言，应先实现相应布局再宣称支持。

## 文档翻译

`README.md` 是英文首页，`README-zh.md` 是简体中文首页；其他译文在 `docs/zh-CN/`，互链英文和中文目录。英文仍是规范参考，Apache 许可证原文保持不变。

示例、命令、API 路径、环境变量和代码注释与英文原文完全一致，只翻译说明、标题和表格。行为变化时同步更新两种语言。每篇译文通过 `translation-source` HTML 注释记录仓库相对源路径及 SHA-256 内容版本。审阅翻译后，用 `sha256sum SOURCE`（Linux）或 `shasum -a 256 SOURCE`（macOS）更新摘要。仓库检查会拒绝过期源版本；仅修改摘要不算更新译文。
