# 获取帮助

[English](../../SUPPORT.md) | 简体中文 · [文档目录](README.md)

先阅读[文档目录](README.md)、安装指南和部署指南的排障部分。这是由社区支持的开发软件，不提供响应时间或生产支持保证。

提交 bug 或功能请求前，搜索[已有 issue](https://github.com/philpm/HolePunch/issues)。请注明版本/提交、系统和架构、安装方式、界面语言、复现步骤、预期与实际行为。

使用通用主机名并脱敏日志，不要附带环境文件、访问摘要、数据库备份、私钥、接入码、会话 Cookie 或客户信息。漏洞通过[安全说明](SECURITY.md)报告，不放在公开 issue 中。

贡献代码或翻译请阅读[贡献指南](CONTRIBUTING.md)和[国际化](I18N.md)。
