# HolePunch Self-hosted 产品概览

[English](../OVERVIEW.md) | 简体中文 · [文档目录](README.md)

HolePunch 面向希望在自己的 VPS 和域名上运行隧道的个人与小团队。Cloud 是独立开源产品，详见[仓库边界](EDITIONS.md)。

## 核心使用流程

1. 原生或 Docker 部署服务端，初始化本地管理员，并配置域名和 DNS。
2. 在**客户端**创建设备，运行共享 CLI 并输入一次性接入码。
3. 在**隧道**设置本地地址、端口、协议和公网域名，客户端自动同步，用户无需编辑隧道配置文件。
4. 管理 TCP、UDP、HTTPS/WebSocket 隧道，检查客户端和配置状态，通过**本机网站**发布同一服务器上的其他应用。

## 产品边界

- 单管理员工作区，不提供公开注册、邮件验证、邀请、用户代管或商业套餐。
- 没有客户端/隧道数量产品配额，不进行累计流量统计；端口池、硬件和网络容量仍有限。
- 隧道默认不限速，可选限速由双向流量及所有连接共享；留空不限速，0 禁用。
- 支持完整自定义域名及后缀下的随机子域名，共享核心负责 TLS 授权和冲突检查。
- 必需能力包括密码初始化、会话、CSRF、令牌撤销、离线授权租约和备份。
- 桌面布局使用侧栏，移动端使用导航抽屉。
- CLI 是主要客户端，可选桌面应用继续保留在本仓库。
- 开发、文档原文、注释和诊断使用英文。维护中的 GUI 默认英文，并提供持久化的语言选择，当前支持英文和简体中文，详见[国际化](I18N.md)。

## 验收

独立克隆必须能在没有 Cloud 源码时构建和测试。验证不限速/限速切换、自定义域名 HTTPS、TCP/UDP、热重载、撤销、恢复和备份。检查两种界面语言、插值、无障碍标签、用户数据与草稿保护。目标平台部署和持续负载验收仍是发布要求。
