# Self-hosted 路线图

[English](../ROADMAP.md) | 简体中文 · [文档目录](README.md)

产品边界见[版本与仓库边界](EDITIONS.md)。Cloud 应用计划在其独立仓库维护，生产运维数据和客户信息留在 Git 之外。

## 已实现的本地能力

独立共享核心与 Self-hosted 构建、CLI 一次性接入、侧栏控制台、自定义/随机域名、不限速或可选隧道限速、本机网站、备份恢复和版本类型数据保护。Cloud 业务处理器已移出本仓库。

英文是开发和文档原文语言。Web、兼容页面、桌面 GUI 共用英文/简体中文翻译，支持持久语言选择和桌面托盘标签；CI 验证词条。

三种部署方式均已实现：验证过归档的交互式原生安装、克隆构建运行、Linux Docker Compose。原生设置生成私密配置并检查监听冲突，Linux systemd 可监督整套进程，macOS/Windows 使用可移植前台运行器。两种 Compose 均支持自定义端口和首次管理员初始化。支持范围及发布产物要求见[安装](INSTALLATION.md)。

控制台提供可见语言切换与认证后的四步设置向导，完成状态保存在服务端；部署命令输出浏览器访问信息和初始凭据，自动化可选择脱敏。

## P0：社区发布验收

- 验证独立克隆、固定依赖、安装升级回滚及两个仓库的 CI。
- 在真实 Linux systemd、Linux Docker、Windows 和 Intel/ARM Mac 上执行验收。
- 验证公网 DNS/CA、断网恢复、24 小时混合负载及资源上限。
- 审查源码与 Git 历史中的运维信息，建立私密漏洞报告渠道，再决定发布。
- 与社区审阅英文术语和中英文翻译，保持词条一致性为必需检查。

## P1：易用性

加入桌面一次性接入、诊断日志导出、自动原生升级及可选 macOS/Windows 后台服务集成。继续共享客户端核心，桌面维护在本仓库。欢迎按国际化流程增加界面语言。

## 后续工作

定义远程节点协议和健康检查。全球路由选择需要真实链路测量，当前不承诺此能力。不增加累计流量统计或流量上限。
