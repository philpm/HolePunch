# 安全与信任边界

[English](../../SECURITY.md) | 简体中文 · [文档目录](README.md)

## 身份与管理

Self-hosted 初始化一个邮箱/密码管理员。会话使用 HttpOnly、Secure、SameSite=Strict Cookie，写操作需 CSRF。支持改密和撤销会话，不提供公开注册、邮件恢复、MFA 或多租户。

管理员可配置节点并发布本地服务，包括 Caddy API、Ask URL 和本机网站，因此仅向可信运营者授予管理权限。设备以一次性码兑换独立长期令牌，服务端保存令牌摘要；修改管理员密码不会撤销设备。

`HP_ADMIN_TOKEN` 是兼容配置，不是正常 Web 登录凭据。`HP_LEGACY_ADMIN=1` 显式启用支持的运维端点 Bearer 兼容认证，不恢复旧资源写入。

## 网络与数据

- 公网控制台使用 HTTPS。服务端和 Caddy Admin 默认监听回环地址，不公开 3000/2019。
- 客户端拒绝公网 HTTP 和携带令牌的重定向，仅允许本地回环 HTTP。
- 客户端到入口使用 Noise；公网 TCP/UDP 服务仍需要应用认证，Noise 不替代它。
- 本机网站代理回环 HTTP，不执行 PHP 或管理应用进程。管理员负责判断哪些服务可公开，端口冲突检测不能识别全部敏感应用。
- Unix 运行目录 0700，凭据文件 0600。CLI 使用受保护文件，桌面可用系统凭据库；Windows 目录 ACL 需另行管理。
- 数据库、生成 TOML/Caddy 配置、备份和测试目录可能含服务密钥，不能公开。Caddy 证书和环境配置需另行备份。
- Web 响应设置 CSP、防嵌入、nosniff 和 no-referrer，不开放任意 CORS；部署访问控制仍必需。
- 词条包是经审阅的可信资源，不来自远程翻译服务。模板保留用户数据转义，不能插入未转义用户内容。

## 运行限制

配置授权 90 秒不刷新后，客户端暂停转发。服务端网关独立使用 15 秒策略租约，撤销/更新仍依赖协调成功。服务端退出关闭网关连接，重启后新连接恢复，但旧连接不会保持。

轮换 Ask 密钥可能在 Caddy 同步前短暂影响新证书申请。禁用域名不会撤销已有证书。

审计最多保留 1000 条并返回最近 100 条，不防篡改，也不是长期归档。客户端日志保留约 4 MiB，可能含服务地址。主机网卡速率不是可用于隧道计费的累计流量数据。

## 漏洞与依赖

发布前扫描审阅当前锁文件，见[依赖审查](RELEASE.md#依赖审查)。历史扫描不能证明当前安全。报告遵循下文私密流程。

## 支持版本与报告

安全修复目前针对 `main` 和最新开发版本，旧预览不保证维护，尚无稳定支持周期。

使用 [GitHub 私密漏洞报告](https://github.com/philpm/HolePunch/security/advisories/new)，包含受影响提交、影响、最小复现和脱敏诊断。不要在公开 issue 中发布利用细节、令牌、数据库或客户信息。

若私密报告不可用，通过[所有者主页](https://github.com/philpm)提供的私密联系方式安排渠道，不在公开求助中披露漏洞。维护者需在公开发布前启用并验证渠道。修复与披露会和报告者协调，目前不承诺响应时间。
